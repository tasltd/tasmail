TASMail — Junk / Spam User Guide

Product: Webmail UI for any IMAP/SMTP server (BYOK)

Live: https://mail.techatscale.io

1. Junk / Spam Folder

TASMail automatically routes suspected spam and phishing emails to the "Junk" or "Spam" folder.

1 Locate Junk Folder

Click the Junk or Spam folder in the sidebar. Suspected spam emails are listed here.

Screenshot:

2 Review Messages

Review emails in the Junk folder. Legitimate emails (false positives) can be rescued.

3 Mark as Not Spam

Select a message and click Not spam or Move to inbox to move it back to the inbox and train the spam filter.

4 Delete Junk

Select spam messages and delete them permanently.

5 Adjust Spam Filter

Some configurations allow adjusting spam filter sensitivity via settings or contacting support.

2. Important Notes

  • Spam filtering uses a combination of Bayesian analysis, sender reputation, and content inspection.
  • False positives (legitimate email marked as spam) can be rescued by marking as "Not spam".
  • Bulk spam sweeps are discouraged on production servers — the LXC dev server is the acceptable environment for testing.
  • Demo and Edge servers carry real tenant data — treat as production, never use for dummy data loads.
