# Alt-UI ("Modern") E2E Sweep — 2026-05

Point-in-time audit of the alt-UI theme served from `/modern/` (built from
`themes/shadcn-prototype/`). Captured 2026-05-29 as part of TMAIL-292.

## Scope

The alt-UI is the shadcn/ui + Radix + Tailwind theme that ships into
`frontend/public/modern/` via `npm run build:alt-ui`. Logged-in users hop in
via the wand-icon button in the classic SPA's `TopBar` and hop back via the
`← Classic` link in the alt-UI `Navbar`. Both UIs share the JWT pair via
`localStorage` because they're served from the same origin.

This sweep validates the full user-visible round-trip end-to-end against the
production backend (`https://mail.techatscale.io`) and asserts API state
changes alongside UI assertions per the project's SPA E2E HARD RULE.

## What the spec asserts

1. **BYOK bootstrap** — `POST /api/auth/signup` + `POST /api/imap-configs` +
   `POST /api/smtp-configs` so the alt-UI has live IMAP folders to render.
2. **Wand-icon hop** — `a[title="Try the modern UI"]` in the classic TopBar
   navigates the browser to `/modern/index.html` via a full-page anchor (so
   React Router doesn't intercept).
3. **AuthGate JWT reuse** — the `access_token` written by the classic SPA is
   still in `localStorage` after the hop. We never bounce through `/login`.
4. **EmailList live data** — the alt-UI `EmailClient` `useQuery(['folders'])`
   + `useQuery(['messages', activeFolder])` populate the sidebar + list from
   `/api/folders` and `/api/folders/{folder}/messages` on the real mailbox.
5. **EmailReader hydration** — clicking a row triggers
   `useQuery(['message', folder, uid])` → `GET /api/folders/{f}/messages/{uid}`
   and renders the sanitized HTML body in a new `<h2>` + reader pane.
6. **ComposeModal round-trip** — the modal posts to `/api/messages/schedule`
   (via `scheduledApi.scheduleSend`, `delay_seconds: 0` → clamped to 5s by the
   backend). Verified by polling `GET /api/messages/scheduled` for the new row
   and falling through to `GET /api/folders/Sent/messages` once the email
   scheduler worker fires.
7. **← Classic hop back** — the alt-UI `Navbar` link routes the browser to
   `/app`. JWT survives the second full-page nav; the classic SPA Compose
   button is visible again.

## Code-side findings

### CalendarView is fully wired to live `/api/calendar/events`

`themes/shadcn-prototype/src/features/calendar/CalendarView.tsx` reads via
`listEvents()` and mutates via `createEvent()` + `cancelEvent()` against the
real Axum endpoints. The previous in-memory `initialEvents` array is gone
(TMAIL-235 / TMAIL-236 / TMAIL-237). The CLAUDE.md note that "CalendarView …
[is] still on `src/data/mockData.ts`" is **stale** and corrected as part of
this sweep.

### AdminDashboard is fully wired to live admin APIs

`themes/shadcn-prototype/src/features/admin/AdminDashboard.tsx` reads via
`adminUsersApi.list()`, `adminDomainsApi.list()`, and `quotaApi` against
`/api/admin/users`, `/api/admin/domains`, and `/api/quota`. The previous
`mockMailboxes` / `mockStats` arrays are gone (TMAIL-232 / TMAIL-233). Same
CLAUDE.md note correction applies.

### `themes/shadcn-prototype/src/data/` no longer exists

`grep -rn "from '@/data\|mockData" themes/shadcn-prototype/src/` returns only
two hits — both inside `types/ui.ts` and `AdminDashboard.tsx` comments
describing what *used to* be there (TMAIL-239). No live import paths.

## What's still on the to-do list (NOT scoped to TMAIL-292)

Logged here for future tickets:

* **Compose ergonomics** — the alt-UI ComposeModal has no Cc/Bcc default
  visibility (toggled by the user), no signature picker, and no scheduled-send
  date picker. The classic SPA has all three. Not blocking; flag for a future
  TMAIL ticket if the alt-UI is promoted to the default theme.
* **Reader actions** — Reply / ReplyAll / Forward buttons render in the alt-UI
  EmailReader but only the Forward button has a real handler (calls
  `onCompose()`). Reply/ReplyAll are inert placeholders. Out of scope for the
  E2E sweep but worth a follow-up.
* **Sidebar mobile sheet** — the `md:hidden` overlay works but no animation;
  fine for desktop-first beta. No regression risk.

## Reproducing locally

```bash
# 1. Make sure the alt-UI bundle is fresh
cd frontend && npm run build:alt-ui

# 2. Run against the production tunnel (default)
npx playwright test alt-ui-modern.spec.ts --project=firefox

# 3. Or run against a local backend
PLAYWRIGHT_BASE_URL=http://localhost:5273 \
  npx playwright test alt-ui-modern.spec.ts --project=firefox
```

The spec is **idempotent** — `beforeAll` and `afterAll` hard-delete the
`noreply@techatscale.io` mailbox via the `db-cleanup` helper so re-runs are
clean.
